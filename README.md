# MyPulse360
MyPulse360 is a comprehensive mobile health management application designed specifically for private clinics in Malaysia. It streamlines the entire patient journey from appointment booking to prescription management and post-visit care, while empowering patients to take control of their health through an intelligent Health Dashboard.
The app serves three primary user groups:

Patients: Book appointments, track health metrics, manage prescriptions, and set wellness goals
Doctors: View patient data, conduct consultations, issue e-prescriptions, and generate digital certificates
Pharmacists: Verify prescriptions, manage inventory, and track medication adherence
Key Problem Solved

Patients in private clinics experience a fragmented journey with multiple queues, paper-based records, and no centralized health tracking. MyPulse360 eliminates this through a unified digital platform that improves patient satisfaction and clinic operational efficiency.

🏗️ Architecture
Clean Architecture Layers
Presentation Layer
    ├── Screens/Pages
    ├── Widgets
    └── Riverpod Providers (UI State)
           ↓
Domain Layer
    ├── Use Cases
    ├── Entity Models
    └── Repository Interfaces
           ↓
Data Layer
    ├── Remote (Supabase, APIs)
    ├── Local (Hive, SharedPreferences)
    └── Repository Implementations
Data Flow
User Input → Presentation Layer → Use Case → Domain Logic →
Data Layer → Repository → Remote/Local → Database ↔ Response
State Management

Using Riverpod for:

✅ Reactive state management
✅ Dependency injection
✅ Async data handling
✅ Real-time data streams

Example:

dart
final patientProvider = FutureProvider<Patient>((ref) async {
  return ref.watch(patientRepositoryProvider).getPatient(userId);
});

final appointmentsStreamProvider = StreamProvider<List<Appointment>>((ref) {
  return ref.watch(appointmentRepositoryProvider).watchAppointments(userId);
});
🗄️ Database Schema
Key Tables
Table	Purpose	Records
users	User accounts & auth	10K-100K
patients	Patient-specific data	10K-100K
health_metrics	Vital signs & measurements	1M+
wellness_goals	Patient health goals	100K+
appointments	Appointment scheduling	100K+
prescriptions	E-prescriptions	500K+
notifications	Push notification logs	10M+
inventory	Pharmacy stock	10K-100K

All tables include Row-Level Security (RLS) policies for data protection.

🔒 Security
✅ JWT Authentication - Secure token-based auth
✅ Role-Based Access Control - Fine-grained permissions
✅ Row-Level Security - Database-level data isolation
✅ Data Encryption - Passwords hashed with bcrypt
✅ HTTPS/TLS - All communications encrypted
✅ HIPAA Compliance - Healthcare data protection ready
✅ Audit Logging - All data access logged
